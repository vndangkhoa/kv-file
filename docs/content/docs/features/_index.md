kv-file blends the best aspects of classic desktop operating systems into an ultra-responsive web interface.

## 1. macOS Finder Miller Columns

- **Cascading Column Browser**: Clicking any folder smoothly cascades a new column to the right.
- **Fluid Keyboard Navigation**: Navigate effortlessly using the arrow keys (`↑`, `↓`, `←`, `→`).
- **Terminal Inspector Preview**: Selecting a file in the final column displays a live inspector preview with metadata, dimensions, and action buttons.

## 2. Windows Explorer Navigation

- **Hierarchical Directory Tree**: Collapsible left sidebar with **Quick Access**, mounted storage drives, and an expandable tree.
- **Dual Address Bar**: Clickable segmented breadcrumbs with an instant hotkey (`Ctrl+L`) to toggle an editable path bar.
- **Action Ribbon Toolbar**: One-click buttons for New Folder, Upload, Cut, Copy, Paste, Rename, Delete, and Sharing.
- **Status Bar**: Live feedback on total item count, selected byte size, disk free quota, and active WebSocket connection status.

## 3. macOS Quick Look (`Spacebar`)

Press `Spacebar` on any selected item to trigger an overlay preview:
- **Media Player**: Video (with fast scrub seeking) and Audio playback.
- **Images & Photos**: High-resolution zoom and pan preview.
- **Documents & Code**: PDF viewer, Markdown rendering, and syntax-highlighted code.

## 4. Multi-View Mode Switcher

Easily switch viewing modes with one click:
- **Miller Columns** (macOS multi-column flow)
- **Detailed List** (Windows Explorer detailed sortable columns)
- **Grid View** (Large thumbnail cards)
