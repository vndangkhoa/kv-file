kv-file is designed for high-efficiency keyboard-first workflows.

---

## 1. Command Palette (`Ctrl + K` or `Cmd + K`)

Press `Ctrl + K` anywhere in the app to open the quick launcher:

- **Fuzzy Search Across Roots**: Search for any file or folder across all mounted storage roots simultaneously.
- **Quick Action Commands**:
  - `Toggle Theme`: Switch between Light and Dark mode.
  - `Switch View`: Jump between Columns, Detailed List, and Grid modes.
  - `Toggle Split View`: Split or unsplit the explorer window.
  - `Open Recycle Bin`: Open the Trash modal.
  - `New Folder`: Trigger folder creation dialog.
  - `Upload Files`: Open upload picker.

---

## 2. Action Ribbon Toolbar

Located right below the address bar, the Ribbon offers immediate access to primary file actions:

- **New Folder** (`Ctrl + Shift + N`): Create a directory in the current path.
- **Upload**: Open multi-file drag-and-drop dialog.
- **Cut (`Ctrl + X`) / Copy (`Ctrl + C`) / Paste (`Ctrl + V`)**: Standard clipboard file manipulation.
- **Rename (`F2`)**: Modify the filename of the active item.
- **Delete (`Delete` or `Backspace`)**: Move selected items safely to the Trash bin.
- **Share**: Generate a public sharing link.
- **Download**: Stream the selected files as an uncompressed download or ZIP package.

---

## 3. Right-Click Context Menu

Right-clicking any file or folder reveals an intelligent context menu:
- **Open / Quick Look** (`Space`)
- **Copy / Cut**
- **Download**
- **Share**
- **Rename** (`F2`)
- **Move to Trash** (`Delete`)

---

## 4. Complete Desktop Keyboard Shortcuts

| Shortcut | Action | Description |
| :--- | :--- | :--- |
| `Ctrl + K` / `Cmd + K` | **Command Palette** | Open global search & command launcher. |
| `Space` | **Quick Look** | Preview selected file (video, audio, image, PDF, code). |
| `Ctrl + L` | **Edit Address Bar** | Focus path input to type directory destination. |
| `Alt + S` | **Toggle Split View** | Toggle dual-pane side-by-side explorer view. |
| `F5` | **Copy to Other Pane** | In split view, copies selected items to opposite panel. |
| `F6` | **Move to Other Pane** | In split view, moves selected items to opposite panel. |
| `F2` | **Rename** | Rename the currently selected item. |
| `Ctrl + Shift + N` | **New Folder** | Create a new directory in active path. |
| `Ctrl + A` | **Select All** | Select all files and folders in current directory. |
| `Ctrl + C` | **Copy** | Copy selected items to internal clipboard. |
| `Ctrl + X` | **Cut** | Cut selected items to internal clipboard. |
| `Ctrl + V` | **Paste** | Paste clipboard items into active folder. |
| `Delete` / `Backspace` | **Move to Trash** | Soft-delete selection into Recycle Bin. |
| `Alt + ↑` / `Backspace` | **Go Up** | Navigate to parent directory. |
| `↑` / `↓` | **Navigate Items** | Move selection up and down in list or column. |
| `←` / `→` | **Navigate Columns** | Switch parent/child columns in Miller view. |
| `Enter` | **Open Item** | Open directory or start media preview. |
| `Escape` | **Clear / Close** | Deselect items or close active modal/palette. |
